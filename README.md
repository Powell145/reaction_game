REACTION GAME НА ARDUINO
=======================

Учебный проект для освоения LCD-дисплея 1602 и работы с кнопками на Arduino.

О ПРОЕКТЕ
---------
Это простейшая игра на реакцию, созданная исключительно в учебных целях.
Проект помогает разобраться с:
- Подключением и работой LCD 1602 (HD44780)
- Использованием машины состояний (state machine)
- Работой с кнопками (антидребезг, INPUT_PULLUP)
- Функцией millis() вместо delay()
- Выводом текста и центрированием

Цель — не идеальная игра, а понимание того, как работает LCD и базовые приёмы Arduino.

КАК ИГРАТЬ
----------
1. На экране "Press button" — нажмите кнопку
2. Идёт отсчёт 3... 2... 1...
3. Случайная задержка 1–5 секунд
4. Появляется ">>> GO! <<<" — жмите как можно быстрее!
5. На экране время реакции в миллисекундах
6. Если результат лучше — "NEW RECORD!"

ВНИМАНИЕ: Нажали до "GO!" — "TOO EARLY!"

СХЕМА ПОДКЛЮЧЕНИЯ
-----------------

LCD 1602:
| LCD Pin | Название | Arduino          |
|---------|----------|------------------|
| 1       | VSS      | GND              |
| 2       | VDD      | 5V               |
| 3       | V0       | Потенциометр 10к |
| 4       | RS       | D9               |
| 5       | RW       | GND              |
| 6       | E        | D8               |
| 11      | DB4      | D7               |
| 12      | DB5      | D6               |
| 13      | DB6      | D5               |
| 14      | DB7      | D4               |
| 15      | A        | 5V через 220 Ом  |
| 16      | K        | GND              |

Кнопка:
D2 ──── [кнопка] ──── GND
pinMode(2, INPUT_PULLUP);

Зуммер (опционально):
Зуммер ──── D3

КОМПОНЕНТЫ
----------
- Arduino Uno / Nano / Mega
- LCD 1602 (16x2)
- Потенциометр 10 кОм
- Кнопка
- Резистор 220 Ом
- Зуммер (опционально)
- Провода, макетная плата

ЗАПУСК
------
1. Клонируйте репозиторий
2. Откройте reaction_game.ino в Arduino IDE
3. Подключите по схеме
4. Загрузите скетч
5. Нет текста на экране? Крутите потенциометр!

ПРОБЛЕМЫ
--------
| Проблема                  | Решение                          |
|---------------------------|----------------------------------|
| Экран тёмный              | Проверьте питание и подсветку    |
| Чёрные квадраты           | Крутите потенциометр             |
| Иероглифы                 | LCD не поддерживает кириллицу    |
| Кнопка срабатывает сама   | Проверьте INPUT_PULLUP           |
| Дребезг кнопки            | Увеличьте delay(20) до delay(50) |

ЗАМЕТКИ
-------
- Кириллица на LCD 1602 не поддерживается (HD44780).
  Нужен I2C-модуль или createChar().
- Потенциометр критичен — без него контраст не настроен.
- RW обязательно к GND.
